# Video wiki schema

Read this when building the wiki, labeling checkpoints, or querying the corpus.

## Query routing

| Type | Example | First path |
|---|---|---|
| Global topic/flow | 이 영상은 무엇인가 | Brief and scene-log narrative; no new observation |
| Local moment/action | 언제 X가 일어났나 | `va search` + checkpoint span; inspect locally if needed |
| Relational | A와 B 사이 무슨 일 | Wiki relations and entity pages |
| Evidential text/number | 화면 숫자가 몇인가 | OCR first, then full-resolution fallback |

## Scene-log narrative and theme

- The one-line summary promoted to INDEX is not claim-bound. Write a
  video-level overview checked against supported ledgers; the first
  checkpoint must not masquerade as the summary.
- With ending coverage, add `## 테마`: value, mechanism, result, one
  proposition — only when the mechanism cites a concrete ledger event, and
  never invent a result to fill the shape.

Layers: **ledger** (video, append-only `checkpoints.jsonl`, image provenance)
/ **agent wiki** (`va-out/wiki/`, regenerated by `va wiki`: entity pages, tag
index, relation ledger/graph, quotes) / **schema** (this document). Query wiki
and ledgers first; reinspect source media only when stored evidence is
insufficient.

- **Human display:** Obsidian surfaces use human language (original title,
  Korean display status, one-line summary). Machine keys stay in links and
  JSON — changing them breaks links and caches. URL ingest stores the original
  title in manifest `title`.
- **Canonical labels:** base-form nouns that reveal role or purpose. Keep
  modifiers, state, changing numbers, media terms, and version suffixes in
  `basis`, `situation`, `tags`, or faces.
- **Durable-only entities:** `entities`/`speakers` are recurring people,
  segments, formats, overlays, or actual query targets. One-off props and
  visuals go only in checkpoint `situation`/`tags`. At session start either
  enrich candidates with prose/relations or let them stay demoted.
- **On terminal promotion**, store:
  - `tags`: a small discriminative set per video; extend when needed.
    | Mode | Suggested Korean display tags |
    |---|---|
    | 발화 주도 | 콜아웃 · 클러치 · 티키타카 · 정보전달 · 리액션 · 결론 |
    | 시각 주도 | 리액션 · 벌칙 · 슬랩스틱 · 자막드립 · 리빌 · 몽타주 |
    | 무발화 | 비주얼임팩트 · 전환 · 리빌 · 안무 · 엔드카드 |
    | 텍스트-온-스크린 | 사연 · 반전 · 훅 · 정보 · CTA |
    | 루프 모션그래픽 | 태깅 생략 (변별 정보 없음) |
  - `camera-*`: shot size `camera-클로즈업|미디엄|와이드`; movement
    `camera-고정|팬|줌|핸드헬드`. Apply only when visually certain — these
    drive ROI, camera-relative direction, and cut selection.
  - `task-*`/`tool-*`: procedure step and its tool (instructional videos) —
    feeds procedure pages, skill drafts, and the intent-coherence gate: a
    source sharing no tools with the majority consensus blocks promotion
    until retagged or split.
  - `quotes`: `[{"t":12.4,"speaker":"진행자","text":"…"}]`; only lines needed
    for understanding, 3–10 per video, never transcript copy.
  - `relations`: `[{"s":"진행자","p":"벌칙 부과","o":"멤버A"}]`; active-voice
    causal or interaction edges. Prioritize real cause→effect pairs and
    recurring interactions; never invent a minimum quota.
  - `arc`: `"기"|"승"|"전"|"결"` after convergence; optional for shorts and
    looping motion graphics.
- **Scene-log narrative:** preserve the `tca:narrative` block across rebuilds.
  Write 1–3 content lines, a development summary, and one line per arc stage.
  Order content → mode/tags/keywords → narrative/arc → visual/audio/story
  signals → ledger table → evidence frames; the INDEX summary stays
  video-level.
- **Wiki build:** `va index && va wiki`. Promotion needs a supported
  `verified`/`corrected` checkpoint — visual support: decodable,
  provenance-tracked, time-overlapping media; transcript support: valid
  overlapping segment IDs. Unsupported terminal and `hypothesized` entries
  stay searchable but never enter active entities/tags/relations/quotes.
  `--include-hypotheses` only reproduces legacy all-state projections.
- **Prose blocks:** entity `<!-- tca:notes:start/end -->` survives rebuilds.
  Store role change, notable scenes, series context, and `⚠ 모순:` conflicts
  there. Edits outside the block are discarded.
- **Index-first queries:** `va-out/INDEX.md`/`wiki/INDEX.md` → relevant page →
  `va search` → local frame reinspection only if still insufficient.
- **Cross-video identity:** look up existing speaker labels first; reuse the
  exact canonical label, extra information in `basis`. Ground identity in
  visible evidence; never infer real names.

## Korean human-surface terminology

Human surfaces (scene logs, still indexes, INDEX, wiki) use industry terms.
Never translate machine keys, state values, anchors, JSON, cache names, or CLI
commands. Canonical maps: `corpus_projection.STATUS_KO`, `READINESS_KO`,
`human_reason`.

| Machine term | Korean display |
|---|---|
| verified / corrected / hypothesized | 확인 / 정정 / 추정 |
| converged / cover_gaps / verify_more | 완결 / 공백 남음 / 검증 더 |
| scenes(장면전환) | 컷 전환 N회 |
| highlights(버스트) | 오디오 피크 N곳 |
| filmstrip | 조망 시트 |
| frame / frame-crop | 스틸 / 부분 스틸 |
| capture reason | 촬영 사유(한글 맵, 미등록 소인은 원문 유지) |
| cause hash | 사람 표면 비노출(출처 원장 전용) |
| legacy-untracked | 출처 기록 없음(초기 수집분) |
